| Роль                     | Полномочия                                                                                                                                  | Группа пользователей                                                                                   |
|--------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------|
| **privileged-user**      | Просмотр секретов (операции: get, list, watch на ресурс secrets)                                                                            | Группа привилегированных пользователей (например, специалисты по безопасности)                         |
| **read-only-user**       | Чтение основных ресурсов кластера (pods, services, configmaps, nodes, namespaces: get, list, watch)                                         | Пользователи, которым разрешён только просмотр ресурсов (например, аудиторы, наблюдатели)              |
| **cluster-configurator** | Управление ресурсами кластера (операции: get, list, watch, create, update, patch, delete на deployments, replicasets, services, configmaps) | Пользователи, ответственные за конфигурацию и администрирование кластера (например, DevOps-инженеры)   |
